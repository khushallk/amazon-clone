# 🛒 Amazon Clone Webpage 

A frontend e-commerce website created using **HTML5** and **CSS3** as part of my web development learning journey.

## 📖 About

This project recreates the layout of a modern online shopping homepage. It was built to practice creating a structured webpage with a navigation bar, search area, product categories, hero banner, and footer.

> **Note:** This project is for educational and portfolio purposes only. It is not affiliated with Amazon.

---

## ✨ Features

- 🧭 Amazon-style navigation bar
- 📍 Delivery location section
- 🔍 Product search bar with category selector
- 🛍️ Navigation links for deals, customer service, registry, gift cards, and more
- 🖼️ Hero banner with shopping message
- 📦 Product category cards for clothes, furniture, beauty, toys, electronics, pet care, and more
- ⬆️ Back-to-top section
- 🔗 Multi-column footer with useful links
- 🎨 Font Awesome icons and hover effects 

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- Font Awesome

---

## 📚 What I Learned

- Structuring a complete webpage with HTML
- Using CSS Flexbox for layouts
- Styling navigation bars and footers
- Adding background images to sections
- Working with icons using Font Awesome
- Creating reusable product-card layouts
- Building an e-commerce interface from scratch
